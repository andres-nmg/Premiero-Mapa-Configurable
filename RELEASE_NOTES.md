## Texto para la Release

## Premiero Mapa Configurable 1.0.0

Primera versión pública estable del plugin de Premiero para crear mapas interactivos de cualquier tipo de ubicación en WordPress.

### Funciones principales

- Nombre singular y plural configurable para oficinas, centros, locales, playas u otras ubicaciones.
- Dirección, latitud, longitud y web para cada ubicación.
- Geocodificación automática de direcciones mediante OpenStreetMap Nominatim.
- Hasta tres campos adicionales configurables para los popups.
- Buscador de ubicaciones y encuadre automático de marcadores.
- Personalización de colores con vista previa.
- Importador CSV integrado en los ajustes.
- Shortcode `[mapa]`.
- Pestaña Acerca de con información del proyecto, actualizaciones y contacto de Premiero.
- Actualizaciones automáticas mediante GitHub Releases.

### Requisitos

- WordPress 5.8 o posterior.
- PHP 7.4 o posterior.

### Instalación

Descarga `premiero-mapa-configurable.zip` de los archivos adjuntos de esta Release e instálalo desde `Plugins > Añadir plugin > Subir plugin`.

Después de activarlo, configura el tipo de ubicación y los colores desde sus ajustes y añade `[mapa]` a cualquier página.

> El ZIP instalable se adjunta automáticamente cuando finaliza el workflow **Build WordPress plugin release**.
